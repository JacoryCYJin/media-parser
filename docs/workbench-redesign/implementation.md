# 基础工作区正式接入

日期：2026-09-16。

## 实现

- `BasicWorkspace.vue` 接替原先视频、播客两页导航，提供基础工作区总览及四个完整工具页，沿用确认的灰白外壳、错落模块布局。
- `useWorkbench.js` 分别维护四个工具的输入、结果、任务与最近 10 条新建快照。页面切换保留状态；关闭或刷新应用不恢复这些内存记录。
- 视频继续使用原有解析、格式选择和下载任务接口；播客新增流式音频下载任务，支持暂停、继续、取消与失败重试。重试使用原任务来源快照。
- 语音转写支持本地音频和视频／播客／音频直链，接入 faster-whisper，展示全文、时间片段，支持文本与 SRT 导出。取消采用协作式停止，工作线程确认前显示“正在停止”。
- 大纲接收独立文字或 TXT/MD/SRT 文件，使用现有模型连接。新增 `/api/outline`，保留旧 `/api/video/outline`。停止等待会丢弃后续响应，不能保证远端模型停止计费或计算。
- Electron 主进程负责文件选择、读取与保存；preload 只暴露有限文件能力；Python 负责媒体任务。沿用原设置、Cookie 和下载目录。
- 界面提供中英文；不提供模块连线、组合或复合入口。

## 验证

- 桌面生产构建、Python compileall、差异空白检查通过。
- 六项隔离回归通过：音频下载完整性、暂停继续取消与临时文件清理、本地文件校验、转写取消确认及归属、独立大纲与旧路由兼容、短文本校验。
- 真实 Electron 操作：选择生成的 WAV，完成本地 Whisper 转写；保存 SRT 并核对时间码与内容；返回总览后重新进入仍保留结果。
- 真实 Electron 大纲生成：使用已有 SiliconFlow Dev 连接处理测试文字，成功显示概述与五组层级章节。
- 本地 HTTP 素材实际接入：播客解析 WAV 并下载 221442 字节；yt-dlp 解析 180p HLS 并下载 22700 字节 MP4。测试下载放在临时目录。
- 类型检查使用 `npm run typecheck -- --ignoreDeprecations 5.0` 通过。仓库原有 `ignoreDeprecations: "6.0"` 与当前安装的 TypeScript 不兼容，原命令仍会报配置错误；本次未修改该配置。
