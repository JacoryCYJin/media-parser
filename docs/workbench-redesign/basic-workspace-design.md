# 基础工作区原型

日期：2026-09-15。状态：可交互设计原型，未接入正式软件。

## 已确认的产品方向

- 左侧只有“基础工作区”导航入口与底部设置。
- 右侧总览展示视频解析下载、播客解析下载、语音转写、大纲总结四个独立模块。
- 点击模块进入完整工作页；返回总览、切换工具保留当前输入与结果。
- 中性灰白桌面外壳、紧凑控件，四块采用错落宽度和轻微色差，局部方块图案表达积木感。
- 本轮不提供画布、拖动模块、连线、自由组合、复杂工作区入口或 Codex 对话工具台。

入口：`basic-workspace-prototype.html`。可直接打开 HTML，也可使用当前临时预览 http://127.0.0.1:5187/basic-workspace-prototype.html 。预览进程关闭后，本地 HTML 仍可使用。

## 页面与行为

### 总览

四块按 3:2、2:3 两行交错排列。块内有 SVG 图标、名称、用途与进入箭头。小窗口缩为单列，侧栏保留图标与可访问名称。总览没有任务串联入口。

### 视频解析下载

输入链接 → 解析 → 演示控制“模拟完成” → 显示媒体信息与格式 → 下载 → 暂停/继续、停止、失败重试或模拟完成。视频与仅音频显示不同格式。下载完成后的“在文件夹中显示”只解释原型边界，不打开真实文件夹。

### 播客解析下载

输入单集链接 → 解析 → 模拟完成 → 显示单集信息、原生音频控件和 MP3 下载项。音频控件没有实际音频源，旁边明确标注布局示意。此次仅演示单集，节目多集选择与现成文字稿显示尚未实现。

### 语音转写

本地音频与来源链接两个明确选项。可选择或拖入支持扩展名的音频，只读取文件名，不读取音频内容；也可载入示例。语言选项为自动、中文、英文。开始 → 手动模拟完成/失败，或停止 → 重试。结果含全文和演示时间片段，可复制或导出文本。高级参数明确标为未来正式配置。

### 大纲总结

可选标题、粘贴文字，或导入本地 TXT/MD/SRT（不超过 2 MB）。导入只在本页读取文字，不上传。至少 100 个非空白字符后允许生成。可选择中英文输出。结果为固定演示概述与三个可折叠章节，输入标题会用作结果标题。提供复制与文本导出。

### 设置

界面语言、默认下载目录字符串、大纲模型名称均为演示配置，只存在页面内存，不读取真实账户、Cookie、系统目录或模型连接。修改目录会更新下载页的显示。模型名称不影响固定演示输出。

## 任务与数据生命周期

- 四个工具各有独立的当前任务，切换不会清除数据。
- 运行进度定时增加至 88%，必须用页面底部“演示控制”完成或失败，避免暗示真实任务已执行。
- 下载可暂停/继续；转写与大纲不显示暂停按钮。
- 运行中禁用修改输入、新建和恢复历史任务。
- 新建任务将当前非空任务存入本工具历史，最多保留最近 10 条新建快照；历史恢复后可以查看对应输入和结果。
- 修改输入清除该任务旧结果；语言设置切换不翻译已经生成的结果，输出保留生成时的语言。
- 当前状态仅保留在打开的页面内，刷新或关闭页面会重置。没有本地存储、真实任务持久化或自动接续。
- 真实文本导出只产生用户主动操作的演示 TXT。所有媒体信息、大小、进度、转写和大纲均非真实处理结果。

## 正式实现边界

原型新增两个文档目录文件，不改 Electron、Vue、Python、旧原型、站点、配置或运行数据，不新增依赖。

正式实现需要：独立大纲输入与状态、共享转写任务逻辑、本地音频入口、播客下载任务、统一文件与任务结构。四个工具共享设置和底层服务；未来组合能力不在本轮实现。
