# 现有媒体模块 + Codex 工具台

状态：简化版交互原型，未替换正式软件。日期：2026-09-15。

## 1. 本轮范围

用户反馈此前项目、素材库、成品版本的设计过于复杂，已确认回到正式软件现有功能，先拆清模块，再在右侧增加 Codex 工具台。

本轮只修改 `prototype.html` 和本文：撤出项目首页、项目配置、素材库、文档目录与版本管理界面。保留未来内容制作工作台的扩展方向，但不把未来功能提前放入当前导航。

不修改正式 Electron/Vue/Python 实现、真实文件、Cookie、模型配置、启动修复或网站。不新增依赖，不登录账号，不调用模型，不提交或推送。

预览：http://127.0.0.1:5187/prototype.html 。HTML 也可直接打开，无外部资源依赖。

## 2. 现有模块拆解：实现事实

| 模块 | 当前职责 | 主要代码 |
| --- | --- | --- |
| 应用导航 | 切换视频、播客，打开设置 | `apps/desktop/src/renderer/src/App.vue`、`components/AppSidebar.vue` |
| 视频解析 | 输入 URL、媒体信息、格式列表 | `views/VideoParser.vue`、`components/video-parser/VideoParserRegistry.vue` |
| 播客解析 | 节目信息、音频地址、试听、文字预览与转写 | `views/PodcastParser.vue` |
| 下载与转写 | 创建处理任务、轮询状态与处理结果 | `components/video-parser/useVideoDownloads.js` 及播客页面对应逻辑 |
| 大纲 | 基于有效文本整理大纲 | `components/video-parser/useVideoOutline.js`、`VideoOutlinePanel.vue` |
| 设置 | 下载目录、平台信息、模型连接、语言 | `components/SettingsDialog.vue`、`useVideoParserSettings.js`、`VideoParserCookieDialogs.vue` |

表中省略共同前缀 `apps/desktop/src/renderer/src/` 的路径仍属于该目录。以上是功能与现有实现的划分，不代表要为每个模块增加独立页面。

现有播客使用原生 audio 控件。原型保留播放区域位置，但没有真实音频源，明确标注布局示意；这不授权正式迁移时移除试听功能。现有下载与转写的控制接口不同，原型只对下载提供暂停和继续，不把转写暂停伪装为已有能力。

## 4. 简化后的界面

```text
左侧导航             中间操作区                     右侧 Codex 工具台
视频解析             链接输入与解析                 新建 / 历史 / 收起
播客解析             媒体信息                       对话、状态、结果
                     格式与下载                     可展开的执行过程
                     文字与大纲                     当前内容附件
设置                 当前素材的处理进度             输入、发送 / 停止
```

- 左侧仅两个媒体入口和设置；不添加独立的任务中心、项目、素材库或成品页。
- 中间输入、结果、格式、转写和大纲沿用现有业务关系。文字与大纲使用折叠区域，当前素材的处理进度就地显示。
- 右侧独立持续对话，可以不附加素材直接输入；“添加当前内容”把当前来源 URL、文字、大纲做成内存快照。
- 附件标题始终可见，可移除。切换视频与播客不会暗中更换已附加内容；用户主动添加新内容才替换附件。
- 新建对话创建独立输入与消息；历史入口恢复已有对话。界面切换不清除输入和结果。
- 输入区固定在工具台底部，回复区域单独滚动；右侧可收起，窄窗口使用覆盖面板并默认收起。

## 5. 演示流程与限制

### 媒体

输入 HTTP/HTTPS URL → 模拟解析 → 选择格式下载 / 转写 → 在“处理进度”的“演示控制”中手动完成 → 查看文字 / 生成大纲 → 添加到 Codex。

所有媒体信息、时长、格式、文件大小均为示例。转写和大纲采用固定示例文本。原型没有任何真实下载、音频读取或模型请求。

视频初始载入一条示例，播客初始为空。切换模块保留各自输入、解析结果和演示任务；重新解析同一模块会清空该模块上一份演示结果与演示任务，这只是原型简化行为，正式实现的历史策略尚未设计。

### Codex

设置中模拟连接 → 输入要求 → 可选添加当前内容 → 发送 → 在“查看过程”里手动模拟完成 / 失败 / 确认 → 回复或停止 → 继续追问。

失败和停止后可以重试；历史对话保持。当前回复有复制入口，剪贴板不可用时打开文本预览供手动复制。未连接、额度不足时不能发送，也不会自动切换到付费 API。

认证方向仍为 Electron 本地接入官方 [Codex App Server](https://learn.chatgpt.com/docs/app-server)，通过 [ChatGPT 登录](https://learn.chatgpt.com/docs/auth) 使用对应订阅访问。[API 按量计费](https://learn.chatgpt.com/docs/pricing) 为独立可选通道。上述是未来架构方向，本原型只模拟状态。

设置只演示语言、目录、平台方式、模型名称与 Codex 连接状态，不读取或修改真实配置。界面支持中英文，示例媒体标题保留原语言。
